Flagship Product

Perovskite Solar Cell Charge Controller

A dedicated charge-control architecture engineered around the input characteristics of perovskite solar cells — covering everything from raw cell input to protected, monitored, logged output.

Product Photo

The physical board

Architecture

Input → controlled charging → output, with four supporting layers

The block diagram below shows how the eight core capabilities relate: a main flow from solar-cell input through the controlled charging stage to the battery or test platform, with monitoring, parameters, protection, logging and communication layered around the core controller.

Functional block diagram — illustrative of control architecture, not a wiring or circuit-level schematic.

Eight Core Capabilities

What the controller does, end to end

Capability 1

Solar-cell input interface

Accepts the raw electrical output of the perovskite solar cell as the controller's input stage.

Capability 2

Controlled charging stage

Manages the charging profile applied to the connected battery or load, tuned to the cell's characteristics.

Capability 3

Voltage and current monitoring

Continuously tracks voltage and current through the charging path to inform control decisions.

Capability 4

Programmable operating parameters

Operating thresholds and behaviour can be configured for the specific deployment or test scenario.

Capability 5

Protection and fault management

Guards the charging path and connected load against fault conditions.

Capability 6

Data acquisition and logging

Captures operational data over time for analysis, diagnostics or reporting.

Capability 7

User interface or digital communication

Provides a way to observe status and exchange data with an external system.

Capability 8

Custom integration with battery or test platform

Adapts the controller's output stage to the specific battery chemistry or test rig in use.

Why It's Different

Built for perovskite, not adapted from silicon

Generic solar charge controllers are designed around the electrical behaviour of conventional silicon cells. Avimukt's controller is engineered specifically around perovskite solar-cell input characteristics, so the charging stage, monitoring thresholds and protection logic are matched to the cell technology it serves.

Because operating parameters are programmable and the platform supports digital communication, the same core controller can be configured across research bench setups, prototype platforms and fielded systems.
